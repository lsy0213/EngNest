# EngNest · 英语小窝 🪺

一个帮你把英语重新捡起来的桌面应用。定位是"四级过了但几年没用、已经生疏"的学习者，双击 exe 就能用，不需要安装。

## 功能

| 板块 | 内容 | 离线可用 |
|---|---|---|
| 📚 单词 | 记住单个的词。11 本词书，分基础 / 考试 / 行业三组：入门精选、主题词汇、四级、六级、雅思、雅思主题词汇（按话题分章）、托福，以及医学、计算机与科技、法律、经济金融四本行业词书，去重后约 1.6 万词。考试词书可以设置考试日期和目标分，显示倒计时和每天该学多少词；学新词可以乱序。卡片学习 + FSRS 记忆算法复习（卡片可以滑动：← 或往左拖是记住了，→ 或往右拖是没记住，↓ 有点模糊，空格翻开）（可选「看词回忆」或「看中文拼写」，拼写按一次拼对 / 提示后拼对 / 没拼出来自动评分）+ 练习（测验：混合 / 选择题 / 拼写；选词填空：例句挖空选词；**挖词填空**：一句话里把当前词书的重点词挖掉（一句最多 3 个，下面有中文提示），填回去，可以切换美音 / 英音、首字母提示、显示翻译，关掉挖空就是重点词高亮的阅读模式，开了 AI 还能让 AI 用你在学的 3–4 个词造一个新句子；打字：打单词或当前单元的例句，可默写）；四六级、雅思、托福词条带例句、短语和记忆方法，四六级还有真题原句。同一个词在不同词书里共享学习进度。**短语和句子也有间隔复习**：短语课学过的短语和生词本里的句子按记忆曲线安排，看中文说英文，同样可以左右滑。**词根词缀**：27 个常用前缀（含最常用的 20 个）、19 个后缀（按变成名词 / 形容词 / 动词 / 副词分组）、38 个词根，每个配例词拆分，单词卡片背面和查词浮层里自动显示构词（in + spect → 检查），还有「拆词猜义」小测。主题词汇（30 个生活主题，按小组分类，美式音标 + 例句，可连续播放）也在这里：选中「主题词汇」词书后，词库里按主题卡片浏览 | ✅ |
| 🧭 短语与句子 | 把词用起来。**场景路径**： 24 个生活场景、96 课、768 个常用短语（部分带用法提示），闯关解锁；每课混合 5 种题型（选英文、听音选义、点词拼句、选词填空、打字翻译）；每个单元最后是一课「连词成句」单元挑战；**句型专项**：14 课按语法点练连词成句；**跟打听写**：情景口语、场景短语、连词成句、生词本里的句子，看着打或听着打，统计 WPM / 正确率 / 连击；每日一课 + 每周复习测验 | ✅ |
| 🧱 连词成句（在短语与句子里） | 仿句乐部玩法：看中文打英文，每句话从一个词块一步步扩成完整句子（coffee → a cup of coffee → I drink a cup of coffee every morning），每一步都有中文。38 课、152 句、591 步。两种输入：空格换词 + Enter 提交整句（默认），或逐词自动判定。每步完成后展示句子成分解析（主谓宾定状补彩色标注、逐词中文和词性、悬停看说明），Perfect × N 连击动效和音效。快捷键：Ctrl+' 发音、Ctrl+; 显示答案、/ 提示字母 | ✅ |
| 🧩 语法 | 6 章 36 课：句子基础 → 词法 → 时态 → 非谓语 → 从句与虚拟 → 特殊句式，180 道带解析的练习 | ✅（AI 答疑需联网） |
| 🎧 听力 | **听力广场**：为我生成听力（用生词本里的词，AI 写一段对话或独白，两种声音朗读，听完做题）；VOA 原声精听（313 篇美国之音原声，调速、倒退、AB 循环，原文可隐藏 / 模糊 / 显示）；**逐句听写**：生成的听力和 VOA 文章都可以切到听写模式，一句一句（VOA 还能按段）听，随时暂停、重听、调慢，写完和原文逐词对照（写对 / 写错 / 漏写 / 多写），再看中文翻译（VOA 的翻译需 AI，译过的存在本机）；听写句子（逐词比对）、听音选义 | ✅（生成听力需 AI，VOA 音频需联网） |

## 学习计划、复习和统计

- **今日学习计划**：首页按学习目标（重新捡起来 / 四级 / 六级 / 雅思 / 开口说）和水平安排当天要做的事，先复习再学新词，显示大约还要多少分钟。第一次打开有新手引导。
- **水平测试**（首页或 `#/level`，约 8 分钟）：词汇 24 题、语法 12 题、听力 6 题，估算词汇量和欧框等级；结果会推荐词书、调整阅读难度，所有 AI 讲解和 AI 语伴也按这个水平说话。
- **复习用 FSRS 记忆算法**（[ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)）：按每个词记得牢不牢，算出快要忘掉的那天再让你复习；设置里可以选希望记得多少（85% / 90% / 95%）。卡片评错了按 Ctrl+Z 撤销；滑动方向可以改成「→ 记住了」。
- **学习统计**（`#/stats`）：近 30 天复习记住率、未来 7 天复习量、各项能力雷达图、半年打卡。
- **阅读标出生词**：打开后词书里没学过的词浅色底、正在学的虚线，页头显示生词率（2% 以下轻松，5% 以上偏难）。
- **生词本导入导出**：导出成 Anki 能直接导入的文本、带复习记录的 CSV；从 txt / csv / Anki 导出文件导入单词表。

## 运行

```bash
conda create -n engnest python=3.11 -y
conda run -n engnest pip install -r requirements-dev.txt
conda activate engnest
python main.py
```

## 打包和发布

双击 `build.bat`：先跑测试，然后打包成文件夹版（onedir），生成

- `dist\EngNest\EngNest.exe`：直接运行；
- `dist\EngNest-<版本>-portable.zip`：绿色版压缩包；
- `dist\EngNest-Setup-<版本>.exe`：安装包（装了 [Inno Setup 6](https://jrsoftware.org/isdl.php) 才生成）。按用户安装，不需要管理员权限，安装时可以选学习数据放在哪个盘。

不再打成单个 exe：web/ 有接近 200 MB，单文件版每次启动都要先解压到 C 盘的临时目录，启动慢，也更容易被杀毒软件误报。设置环境变量 `ENGNEST_SIGN_PFX` / `ENGNEST_SIGN_PASS` 后会用 signtool 做代码签名。第一次打包时如果还没有 `assets\ecdict.db`，会先下载 ECDICT 并生成。

发布新版本：改 `engnest/__init__.py` 里的 `VERSION`，然后 `git tag v<版本>` 并推送标签，GitHub Actions 会自动打包并发布到 Releases（`.github/workflows/release.yml`）。软件每天会检查一次有没有新版本，「设置 → 关于」里也可以手动检查。

> 打包必须在激活的 conda 环境里进行（`build.bat` 用的是 `conda run`）。依赖系统自带的 WebView2 运行时：Windows 11 已内置；少数老版本 Windows 10 需要安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 接入 AI（可选）

在「设置 → AI 接入」里选择服务商、填入 API Key 即可：

- **OpenAI 兼容接口**：DeepSeek、通义千问、Kimi、智谱 GLM（glm-4.7-flash 免费）、OpenAI，或任何自定义兼容服务；
- **Claude**：使用官方 `anthropic` SDK，默认模型 `claude-opus-5-5`，开启了自动提示缓存和服务端拒答兜底；使用中转服务时填写接口地址。

各家的模型名经常更新，填好 Key 后点「获取列表」可以看到服务商现在提供的模型。AI 回复是边生成边显示的（流式输出）；多轮对话只带最近 24 条，控制费用。「AI 用量」里能看到每个月每个模型用了多少 token，可以填单价估算费用、设每月上限。API Key 用 Windows DPAPI 加密后保存在本机，换了电脑或 Windows 用户就解不开，需要重新填。

## 发音

- **神经网络语音**（默认）：微软 Edge「大声朗读」同款语音，非常接近真人。每句话第一次播放需要联网，之后缓存在本地（缓存上限 500 MB，超过后删最久没用的）。
- **离线神经语音**：开源的 [Piper](https://github.com/rhasspy/piper)，在「设置」里下载一次（约 85 MB）后完全离线，比系统语音自然得多。在线语音连不上时自动改用它。
- **系统语音**：Windows 自带语音，完全离线，最后的兜底。

## 数据

学习数据默认放在 `%APPDATA%\EngNest\`。想放在其他盘：在「设置 → 数据与备份」里「更改位置」（下次启动时自动把数据搬过去），或者在程序旁边放一个 `data_location.txt`，第一行写目录（安装包会让你选），也可以用环境变量 `ENGNEST_DATA_DIR`。

- `progress.db`：学习进度（SQLite，只保存改动过的部分）
- `backups\`：每天打开和关闭时自动备份一份，保留最近 7 天；进度文件损坏时自动用最近的备份恢复。设置页可以恢复到任意一份、导出 / 导入（合并或替换）
- `settings.json`：设置（API Key 和 WebDAV 密码是加密的）
- `ai_cache.db`：AI 翻译、逐句精讲、AI 语伴的对话（花钱生成的，不用重复请求）
- `ai_usage.json`：AI 用量统计
- `library\`：导入的读物；`packs\`：下载的资料包（雅思资料包）
- `logs\`：日志（设置页可以「导出诊断信息」，不含 API Key 和学习内容）
- `webview\`：网页部分的本地存储
- `cache\`：能重新下载的大文件：语音缓存、语音识别模型、离线语音、完整词典、下载的视频、IELTS-practice 题库

卸载时删除这个文件夹即可。

**多台电脑同步**：「设置 → 多台电脑同步（WebDAV）」填坚果云等网盘的 WebDAV 地址和应用密码，打开、关闭软件时和每 15 分钟自动同步。各台电脑的学习记录按记录合并，不会互相覆盖（删掉的记录也不会被别的电脑带回来）。只同步学习进度。

## 局域网访问（手机 / 平板 / 其他电脑）

1. 在电脑上打开 EngNest →「设置」→「📱 局域网访问」→ 开启。
2. 手机连同一个 Wi-Fi，扫设置页上的二维码；或者在浏览器输入页面上显示的地址（如 `https://192.168.0.113:8766/`），再输入 8 位访问码（不分大小写）。
3. 默认用 HTTPS（证书是这台电脑自己签的）：第一次打开时浏览器会提示「不安全」，点「高级 → 继续访问」就行。HTTPS 下手机也能录音（跟读评测、和 AI 语伴说话），识别在电脑上做。
4. 第一次开启时 Windows 可能弹出防火墙提示，请勾选「专用网络」并允许。

说明：

- 用**你自己的访问码**进来，和电脑**共用一份学习进度**，按记录合并，两边同时学也不会互相覆盖。
- **给其他人用**：在「局域网访问」下面的「给其他人用」里加一个人（比如朋友、家人），TA 会拿到自己的访问码和二维码。用这个码进来的人有单独的一份学习进度、生词本、设置和 AI 语伴聊天记录（存在数据目录的 `profiles/` 里，各自每天备份），不会影响你的。可以随时给 TA 换码或删除（删除会连 TA 的记录一起删掉）。
- AI 对话、神经语音在其他设备上都能用；你的 AI Key 只能在电脑上改，Key 的任何部分都不会发给其他设备。
- 其他人的 AI：TA 可以在自己手机的「设置 → AI 接入」里填**自己的 API Key**（加密存在 TA 的 `profiles/<id>/settings.json`，只用于 TA 自己，不算你的用量、不受你的每月上限限制）。没填的话默认**不能用 AI**；你也可以在「给其他人用」里给 TA 开「可以用我的 AI」，这时用你的 Key、算你的用量。
- 访问码用来防止同一网络里的其他人使用你的 AI 额度：同一台设备 10 分钟内输错 5 次会被锁 10 分钟。可以随时在设置里更换访问码。
- 手机浏览器里可以「添加到主屏幕」，像 App 一样打开。
- 在中国大陆，GitHub、维基百科、VOA、TED 经常连不上：下载类会自动换国内镜像，其他的可以在「设置 → 网络」填代理，并用「检查网络」看哪些服务能连上。
- EngNest 关闭后局域网访问也会停止；下次启动时，如果上次是开着的，会自动重新开启。

## 添加学习内容

学习内容都是 `web/data/` 下的普通 JS 文件，按现有格式往数组里加条目就行：

- `words.js`：入门精选词书；`vocab_cet4.js` / `vocab_cet6.js` / `vocab_ielts.js` / `vocab_toefl.js` 由脚本生成
- `topics_*.js`：主题词汇，每行 `单词|音标|中文|例句|例句翻译`
- `phrases.js`：短语课程，每行 `英文|中文` 或 `英文|中文|用法提示`；每个单元的第 4 个参数是它的连词成句课 id。进度按单元 id 记录，单元可以调整顺序，但单元里的课只能往后追加
- `builder.js`：连词成句，每个句子一段，每行一步 `英文|中文`，从短到长；被短语课程单元引用的课是单元挑战，其余出现在「句型专项」（顺序见 `js/pages/course.js` 里的 `PATTERN_ORDER`）
- `builder_notes.js`：连词成句的句子成分标注，一行一句，格式见文件开头注释（新增句子后也要在这里补一行）
- `sentences.js`：情景句子、写作题目、AI 对话场景
- `grammar*.js`：语法课与练习题（`grammar_more3.js` 末尾的 `GRAMMAR_CHAPTERS` 决定章节顺序）
- `films_index.js` / `films/*.js`：影视精听片库和字幕，由 `tools/fetch_videos.py` 生成（在脚本的 `SERIES` 里加系列）；`watch_guide.js`：「正版剧集与频道」的推荐和链接
- `phonics.js`：音标和辨音训练；`linking.js`、`linking2.js`：连读与语调课程（格式见文件开头）；`ipa_audio.js`：音标录音的文件和出处，由 `tools/fetch_ipa_audio.py` 生成；`speak_topics.js`：流利度训练的话题；`morphology.js`：词根词缀（例词用「+」拆分）
- `sitcom.js`、`sitcom_chats.js`：合租日记的人物、地点、主线剧情、支线聊天和公园偶遇，格式见文件开头注释
- `reading*.js`：阅读文章与题目（新文件要加进 `index.html` 和 `tools/fetch_images.py` 的文件列表）
- `books_index.js` / `books/*.js`：原著全文，由 `tools/fetch_books.py` 生成；加书就在脚本的 `BOOKS` 里加一项（Gutenberg 编号、章节标题的正则、中文简介），脚本会核对章节数

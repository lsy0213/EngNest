# 三位角色主题素材

三张输入图由用户提供，仅用作各自角色的编辑目标；不是可直接用于公开发行的授权证明。使用内置 imagegen 的 `background-extraction` 透明背景编辑生成角色图，保存在本目录。透明图是保留角色特征的重绘式抠图，不是源文件像素级分割。白发图的原画在画面四周截断了发丝和衣服，界面用 CSS 渐隐遮罩处理开放边缘。

| 主题 | 素材 | 从对应原图局部像素取的代表色 | 界面处理 |
|---|---|---|---|
| 月桂蔷薇 | `garden-ribbon.jpg` | 蓝绿缎带 `#86C9BF`、蜂蜜金发 `#C5B896`、皮带棕 `#413D2B`；界面辅色取原截图的板岩蓝绿 `#526A6A`、铁锈红 `#865C4F` | 极繁剪贴簿：旧报撕纸、珍珠串、蕾丝、邮票邮戳、压花、蓝蝴蝶与火漆；立绘装在贴胶带的相框里 |
| 银雾流光 | `glass-character.png` | 发色珍珠白 `#EDEDEF`、冷银 `#D0D0D2`、脸颊粉雾 `#EEE4E3`；点缀取参考手账的尤加利灰绿 `#A9BEB6`、小黄花 `#E8CE57`、浅蓝蝴蝶 `#B6DCE2` | 白纸手账：揉皱纸底、整页撕边白纸、旧报剪片、尤加利、满天星、洋甘菊、邮票邮戳、索引卡、票根与虹彩光碟；立绘装在白色蕾丝相框里 |
| 星河晚歌 | `star-character.png` | 藏蓝 `#4D4B63`、丁香紫 `#A88D9F`、薄荷绿 `#7DA094`；立绘裙摆延伸出深蓝绿 `#294C4C` 与浅叶绿 `#9CC0A8` | 深浅绿叶星、丁香发卷、繁复星簇与深蓝绿丝绒 |

取色为原图指定区域的 RGB 中位数；正文和按钮使用同色系更深或更浅的色阶，以保持阅读对比度。

三张角色立绘显示在独立的视口悬浮层，初始位于右上角，可用鼠标或触屏拖动，也能聚焦后用方向键移动；每个主题记住自己的位置。主题图案是基于原画元素新绘的 SVG，位于 `web/css/skin/`，而非从参考网站下载的装饰。首页横幅只保留学习内容。

月桂蔷薇第三版换成缎带少女：`garden-ribbon.jpg` 是从用户提供的游戏截图里裁出的人物区域（生图接口不可用，没有做透明抠图），因此以“贴在剪贴簿上的相片”呈现，背景里的书架成为相片内容。版式参考用户提供的复古拼贴相框与撕纸手账图的材料层次（撕边纸、旧报、蕾丝、珍珠、蝴蝶结、邮票、压花），所有 `garden-*.svg` 由 `tools/gen_garden_scrapbook.py` 按固定随机种子原创绘制，没有复用参考图的像素、排版文字或标识。旧版的 `garden-character.png`、`garden-torn-paper.svg`、`garden-rococo-relief.svg` 已不再被引用。

银雾流光第二版去掉了液态玻璃，改成白纸手账。版式参考用户提供的白色撕纸手账图（揉皱白纸、旧报、尤加利、洋甘菊、小黄花、浅蓝蝴蝶、光碟、横线卡）与复古拼贴相框图（蕾丝、珍珠、缎带、长尾夹），换成冷白银色系；所有 `glass-*.svg` 由 `tools/gen_glass_scrapbook.py` 按固定随机种子原创绘制，没有复用参考图的像素、排版文字或标识。主题名里的“流光”落在一张虹彩光碟上：首页进度环、侧栏徽标、进度条和主按钮的掠光都取自它的反光；立绘相框每隔几秒会有一道光从照片上掠过。每一页用 `glass-sheet.svg` 九宫格 `border-image` 画成一张撕边白纸，夜间换 `glass-sheet-dark.svg`。

最终素材的编辑提示词（`transparent_background: true`）：

1. **月桂蔷薇**：以第一张图为编辑目标，只保留中央完整人物，保持脸、浅金长辫、绿宝石王冠、白色褶边裙、绿色外裙、手套、姿态和原画柔和水彩色；移除城堡、风景、鸽子、光环、栏杆、非服饰花朵和文字。人物全身居中，周围及发丝间透明，不增加物件。
2. **银雾流光**：以第二张图为编辑目标，只保留白发人物的原有肖像、银白发丝、耳侧发束、淡灰眼睛、脸颊、托腮手势和白色露肩衣服；保持原图低对比的珍珠白、冷银与粉雾，不增加背景、文字、装饰或深色描边。角色轮廓外和发丝间使用透明像素。原图衣服与发丝在边缘被截断，界面中使用径向 CSS 遮罩使开放边缘自然消隐。
3. **星河晚歌**：以第三张图为编辑目标，只保留全身人物、深藏蓝与象牙白的巨大帽饰、向右展开的丁香紫长发、白色上衣、深色荷叶裙、腿和手中黄绿色星光；移除森林、湖面、云、散落星星、白底及文字，人物与发丝空隙透明。最终版本针对初版背景残留重新编辑，并补回原图帽饰。

## 薄荷可可（`mintchoco`）

两张输入图由用户提供：猫耳洛丽塔少女的游戏截图（角色），以及一张薄荷巧克力配色的截图（只取颜色，不沿用里面的键盘样式）。

- **角色**：`mintchoco-character.jpg` 是从截图里裁出的全身人物区域（猫耳到鞋尖，520×956）。生图接口返回 401，没有做透明抠图，所以和月桂蔷薇一样以“相片”呈现，背景的米色墙面成为相片内容。相框 `mintchoco-photo-mat.svg` 是外圈钩针狗牙、里圈穿白缎带的方形蕾丝框，`mintchoco-photo-overlay.svg` 压上白缎带蝴蝶结与卷曲缎带尾、四角珍珠、纸蝴蝶和带珍珠的蕾丝名签；CSS 用一条细珠链把它从窗口顶端吊下来。
- **取色**（原图区域的中位数，按色相筛选）：配色图的薄荷 `#B6D5C0` / `#C7D9CC`、可可 `#8E7F72`、黑可可 `#56473A`；角色图的天空蓝 `#B2C2CB`（界面用略提饱和的 `#A9CEDA`）、焦糖 `#9E7354`、深发色 `#463020`、金色 `#CAA67F`。正文和按钮用同色系更深的色阶（`#3E2F27`、`#3F7A67`）保证对比度。
- **界面处理**：奶油 / 薄荷 / 可可三色波点布是主材质，缝着虚线针脚；导航选中项是一截燕尾可可缎带。再叠波点蝴蝶结、马卡龙、夹心蛋糕、糖果、纸杯蛋糕、巧克力条、曲奇、蕾丝圆垫与心形、音符和猫爪。侧栏左缘的天蓝白条纹取自角色的长袜。所有 `mintchoco-*.svg` 由 `tools/gen_mintchoco_skin.py` 按固定随机种子原创绘制，没有复用参考图的像素、文字或排版。
- **第二批参考**（用户另给的四张图：白蕾丝珍珠纸蝴蝶的手账页、穿缎带的悬挂蕾丝方框、薄荷可可粉的格纹蕾丝主页、亚麻蕾丝手帕与衬线字排版）：只取元素和氛围，重新绘制为手帕细蕾丝边框（`mintchoco-hanky*.svg`，border-image 九宫格）、蕾丝标签（`mintchoco-lace-tag*.svg`）、标题蕾丝花边（`mintchoco-lace-trim*.svg`）、心形镂空花边（`mintchoco-lace-heart.svg`）、花体字水印（`mintchoco-script.svg`，用系统自带的 Segoe Script）、钩针蕾丝蝴蝶结、纸蝴蝶、粉 / 白缎面蝴蝶结与格纹纸胶带；格纹背景用 CSS 渐变。参考图里的文字、头像与排版没有复用。

## 星河晚歌的蕾丝夜曲（第三版）

配色和立绘不变，只换材质：沿用薄荷可可主题的蕾丝、珍珠、纸蝴蝶与方形蕾丝框画法（`tools/gen_starry_lace.py` 直接调用 `gen_mintchoco_skin.py` 的绘制函数，把蕾丝换成带丁香灰的白、阴影换成藏蓝），再加夜晚的小物：新月、星星挂坠和深蓝星空衬底。素材是 `web/css/skin/starry-*.svg`（原来的叶星藤蔓 `starry-ornament.svg`、`starry-rule.svg` 已不再显示），样式在 `web/css/skin-starry.css`，加载在 `skin-character.css` 之后、按同样的选择器覆盖。立绘保持原来的透明立绘，不加相框。

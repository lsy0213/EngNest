# 操作系统与系统编程
# 格式：术语 | 英文全称（缩写才写） | 中文 | 一句话解释 | 别名（用 / 分隔，可省略）

OS | Operating System | 操作系统 | 管理硬件资源、给程序提供运行环境的系统软件，如 Windows、Linux | operating system
kernel | | 内核 | 操作系统最核心的部分，直接管理 CPU、内存、设备
kernel space | | 内核空间 | 内核运行的特权内存区域 | kernel mode
user space | | 用户空间 | 普通程序运行的受限内存区域 | user mode / userland
system call | | 系统调用 | 程序请求内核帮忙做事（读文件、开网络连接）的接口 | syscall
driver | | 驱动程序 | 让操作系统能控制某个硬件的软件 | device driver
process | | 进程 | 一个正在运行的程序实例，有自己独立的内存空间
PID | Process ID | 进程号 | 操作系统给每个进程分配的编号（工业控制里 PID 指比例-积分-微分控制）
thread | | 线程 | 进程里的一条执行路径，同一进程的线程共享内存
multithreading | | 多线程 | 一个程序同时用多个线程执行 | multi-threaded
multiprocessing | | 多进程 | 用多个进程同时执行任务
scheduler | | 调度器 | 决定下一个让哪个进程或线程使用 CPU 的模块 | scheduling
context switch | | 上下文切换 | CPU 从一个线程切换到另一个时保存和恢复现场
preemptive | | 抢占式的 | 系统可以强行打断正在运行的任务 | preemption
priority | | 优先级 | 任务谁先谁后的等级
fork | | 派生进程；分叉 | Unix 里复制当前进程创建子进程；GitHub 里复制别人的仓库
exec | | 执行 | 用新程序替换当前进程的内容
parent process | | 父进程 | 创建了别的进程的进程
child process | | 子进程 | 由别的进程创建出来的进程 | subprocess
zombie process | | 僵尸进程 | 已经结束但父进程还没回收的进程 | zombie
orphan process | | 孤儿进程 | 父进程已经退出的进程
daemon | | 守护进程 | 在后台长期运行的服务进程，名字常以 d 结尾，如 sshd（Windows 叫服务）
service | | 服务 | 后台持续运行、对外提供功能的程序
signal | | 信号 | Unix 里通知进程发生了某事件的机制，如 SIGINT（Ctrl+C）、SIGKILL
kill | | 终止（进程） | 结束一个进程；kill 命令其实是发信号
IPC | Inter-Process Communication | 进程间通信 | 进程之间交换数据的方式：管道、共享内存、消息队列、套接字等
pipe | | 管道 | 把一个程序的输出直接接到另一个程序的输入，如 ls 的结果交给 grep 过滤
shared memory | | 共享内存 | 多个进程映射同一块内存来交换数据
mutex | mutual exclusion | 互斥锁 | 保证同一时刻只有一个线程进入临界区的锁 | lock
lock | | 锁 | 防止多个线程同时修改共享数据的机制
semaphore | | 信号量 | 用计数控制同时访问某资源的线程数量
critical section | | 临界区 | 访问共享资源、同一时间只能有一个线程执行的代码段
race condition | | 竞态条件 | 结果取决于多个线程执行先后顺序的错误
deadlock | | 死锁 | 几个线程互相等待对方释放资源，谁也动不了
livelock | | 活锁 | 线程一直在响应对方、却始终没有进展
starvation | | 饥饿 | 某个任务一直得不到资源而无法执行
atomic | | 原子的 | 不可分割、要么全做要么不做的操作 | atomicity
spinlock | | 自旋锁 | 拿不到锁时原地循环等待的锁 | spin lock
condition variable | | 条件变量 | 让线程等待某个条件成立再继续的同步机制
thread pool | | 线程池 | 预先创建一批线程循环使用，避免频繁创建销毁
virtual memory | | 虚拟内存 | 给每个进程一个独立的地址空间，由系统映射到物理内存或磁盘
physical memory | | 物理内存 | 实际的内存条容量
address space | | 地址空间 | 一个进程可以使用的内存地址范围
page | | 页 | 虚拟内存管理的基本单位，常见 4KB；网页
paging | | 分页 | 以页为单位管理和换入换出内存
page fault | | 缺页 | 访问的页不在物理内存里，需要从磁盘调入
swap | | 交换（分区） | 内存不够时把不常用的页暂存到磁盘 | swap space / swapping / page file
MMU | Memory Management Unit | 内存管理单元 | CPU 里把虚拟地址翻译成物理地址的硬件
TLB | Translation Lookaside Buffer | 快表；转换后备缓冲区 | 缓存地址翻译结果的硬件
segmentation fault | | 段错误 | 程序访问了不允许访问的内存而崩溃 | segfault
core dump | | 核心转储 | 程序崩溃时把内存内容保存成文件，用于事后调试 | crash dump
OOM | Out Of Memory | 内存不足 | 内存用完了；Linux 的 OOM killer 会杀掉占内存的进程
file system | | 文件系统 | 在磁盘上组织和管理文件的方式，如 NTFS、ext4 | filesystem
file descriptor | | 文件描述符 | Unix 里进程用来引用打开的文件或套接字的整数 | fd
handle | | 句柄 | 引用一个系统资源（文件、窗口）的标识
inode | index node | 索引节点 | Unix 文件系统里存放文件元数据的结构
directory | | 目录；文件夹 | 存放文件的容器 | folder
path | | 路径 | 文件在目录树里的位置，如 C:\Users 或 /home/user
absolute path | | 绝对路径 | 从根目录开始写的完整路径
relative path | | 相对路径 | 相对当前目录的路径，如 ./data
root | | 根；超级用户 | 文件系统最顶层目录（/）；Linux 的管理员账户
working directory | | 工作目录 | 程序当前所在的目录 | current directory / cwd
home directory | | 主目录；家目录 | 每个用户自己的目录，Linux 下是 ~ | home
mount | | 挂载 | 把一个磁盘或分区接到目录树的某个位置
partition | | 分区 | 把一块磁盘划分成几个独立区域
symbolic link | | 符号链接；软链接 | 指向另一个文件路径的特殊文件，类似快捷方式 | symlink / soft link
hard link | | 硬链接 | 同一个文件的另一个名字，指向同一个 inode
permission | | 权限 | 谁能读（r）、写（w）、执行（x）某个文件 | permissions
chmod | change mode | 修改权限命令 | Linux 修改文件权限的命令，如 chmod 755
chown | change owner | 修改所有者命令 | Linux 修改文件所有者的命令
sudo | superuser do | 以管理员身份执行 | Linux 里临时用 root 权限执行命令
privilege | | 特权；权限 | 执行某些操作的权力
administrator | | 管理员 | 拥有最高权限的用户 | admin
user account | | 用户账户 | 登录系统的身份 | account
stdin | standard input | 标准输入 | 程序默认读取输入的地方，通常是键盘
stdout | standard output | 标准输出 | 程序默认输出的地方，通常是终端屏幕
stderr | standard error | 标准错误 | 程序输出错误信息的通道
redirect | | 重定向 | 把输入输出改到文件等别处，如 > out.txt | redirection
terminal | | 终端 | 输入命令、显示输出的窗口 | console
console | | 控制台 | 终端；也指浏览器开发者工具里的控制台
prompt | | 提示符 | 终端里等你输入命令的符号，如 $ 或 >；也指给 AI 的提示词
bash | Bourne Again Shell | Bash 命令行 | Linux 和 macOS 最常见的 shell
PowerShell | | PowerShell | 微软的命令行和脚本语言
Linux | | Linux 操作系统 | 开源的类 Unix 操作系统，服务器上最常用
Unix | | Unix 操作系统 | 历史悠久的多用户操作系统，Linux 和 macOS 都受它影响 | UNIX / Unix-like
distribution | | 发行版 | 基于 Linux 内核打包的完整系统，如 Ubuntu、CentOS | distro
Windows | | Windows 系统 | 微软的操作系统
macOS | | macOS 系统 | 苹果电脑的操作系统
Android | | 安卓系统 | 谷歌的移动操作系统
iOS | | iOS 系统 | 苹果手机的操作系统
POSIX | Portable Operating System Interface | 可移植操作系统接口 | Unix 类系统的标准接口规范
systemd | | systemd | 大多数 Linux 发行版用来启动和管理服务的系统
cron | | 定时任务 | Linux 里按时间计划自动运行命令的服务 | crontab / cron job
init | | 初始化进程 | 系统启动后的第一个进程（PID 1）
boot | | 启动；引导 | 开机加载操作系统的过程 | booting / reboot
BIOS | Basic Input/Output System | 基本输入输出系统 | 主板上的固件，开机时检测硬件并引导系统
UEFI | Unified Extensible Firmware Interface | 统一可扩展固件接口 | 取代 BIOS 的新一代固件标准
registry | | 注册表；镜像仓库 | Windows 存放系统配置的数据库；Docker 里存放镜像的服务
shortcut | | 快捷方式；快捷键 | 指向文件的链接；键盘组合键
clipboard | | 剪贴板 | 复制粘贴时临时存放内容的地方
task manager | | 任务管理器 | Windows 查看和结束进程的工具
CPU usage | | CPU 占用率 | CPU 忙碌时间的百分比 | CPU utilization
load average | | 平均负载 | Linux 里一段时间内等待 CPU 的平均任务数
I/O bound | | I/O 密集型 | 主要时间花在等待读写的任务 | IO-bound
CPU bound | | CPU 密集型 | 主要时间花在计算的任务 | CPU-bound
cache | | 缓存 | 把常用数据放在更快的地方，下次直接用
page cache | | 页缓存 | 操作系统把读过的文件内容缓存在内存里
buffer cache | | 缓冲缓存 | 缓存磁盘块数据的内存
mmap | memory map | 内存映射 | 把文件直接映射到内存地址空间来读写
polling | | 轮询 | 反复主动检查状态是否变化
epoll | | epoll | Linux 高效监听大量文件描述符事件的机制 | select / poll / kqueue
I/O multiplexing | | I/O 多路复用 | 一个线程同时监视多个连接的读写事件
hypervisor | | 虚拟机监控器 | 在一台物理机上运行多个虚拟机的软件，如 VMware、KVM
virtualization | | 虚拟化 | 用软件把一台物理资源虚拟成多份 | virtualize
guest | | 客户机 | 运行在虚拟机里的操作系统 | guest OS
host machine | | 宿主机 | 运行虚拟机的物理机器 | host OS
WSL | Windows Subsystem for Linux | Windows 的 Linux 子系统 | 在 Windows 里直接运行 Linux 环境
emulator | | 模拟器 | 在一种平台上模拟另一种硬件或系统 | emulation / simulator
sandbox | | 沙盒；沙箱 | 把程序关在受限环境里运行，防止它影响系统
uptime | | 运行时间；可用时间 | 系统连续运行了多久；服务的可用率
patch | | 补丁 | 修复问题的小更新；也指代码差异文件
update | | 更新 | 安装新版本
upgrade | | 升级 | 换成更高版本
install | | 安装 | 把软件放到系统里并配置好 | installation / installer
uninstall | | 卸载 | 从系统里删除软件
portable | | 便携版；可移植的 | 不用安装、直接运行的软件；能在不同平台上运行的代码
locale | | 区域设置 | 语言、日期格式、货币等地区相关设置
timezone | | 时区 | 地区使用的标准时间 | time zone

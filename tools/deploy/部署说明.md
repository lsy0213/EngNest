# 在服务器上部署 EngNest（服务器模式）

服务器模式不开窗口，大家用浏览器打开网站，各自注册账号（要管理员给的邀请码），学习进度、设置、AI Key 按账号保存在服务器上。
代码见 `engnest/server.py`（网页和接口）、`engnest/accounts.py`（账号）。下面以 Ubuntu 24.04、腾讯云轻量服务器为例。

## 1. 上传代码

在自己电脑上（项目目录）打包：代码 + 内置词典 `assets/ecdict.db`（没有的话先运行 `python tools/build_dict.py`）。

```bash
tar czf engnest.tar.gz --exclude=.git --exclude=build --exclude=dist --exclude=tools/raw --exclude=__pycache__ .
scp engnest.tar.gz root@<服务器 IP>:/tmp/
ssh root@<服务器 IP> "mkdir -p /opt/engnest/app && tar xzf /tmp/engnest.tar.gz -C /opt/engnest/app && rm /tmp/engnest.tar.gz"
```

## 2. 初始化服务器（一次）

```bash
ssh root@<服务器 IP> "bash /opt/engnest/app/tools/deploy/setup.sh <服务器公网 IP>"
```

它会：加 2 GB 交换空间、装 Python 环境、建一个专门运行 EngNest 的系统用户 `engnest`（不用 root 运行）、
装 systemd 服务（开机自动启动、崩溃自动重启）。数据都在 `/opt/engnest/data`。

前面还会装 Nginx（HTTPS、HTTP/2、压缩、缓存），EngNest 本身只听本机的 8767。
然后在腾讯云控制台 → 轻量服务器 → 防火墙，放通 TCP 8766（网站）和 TCP 80（申请证书用）。

## 2.5 换成正规 HTTPS 证书（强烈建议）

setup.sh 先放一个自签名证书顶着。**浏览器不认的证书，Chrome / Edge 不会缓存网页文件，每次打开都要重新下载十几 MB**，
所以要换成 Let's Encrypt 的正规证书（免费，只有 IP 也能申请）。用的是 [lego](https://github.com/go-acme/lego/releases)：
在自己电脑上下载 `lego_*_linux_amd64.tar.gz`（核对 checksums），解压后传上去：

```bash
scp lego root@<服务器 IP>:/usr/local/bin/lego
ssh root@<服务器 IP> "chmod 755 /usr/local/bin/lego"
ssh root@<服务器 IP> "CERT_EMAIL=<你的邮箱> bash /opt/engnest/app/tools/deploy/cert.sh <服务器公网 IP>"
ssh root@<服务器 IP> "systemctl enable --now engnest-cert.timer"
```

- IP 证书只有 6 天多有效期（Let's Encrypt 的规定），定时器每天检查两次，剩一半时自动续，续完自动重载 Nginx。`journalctl -u engnest-cert` 看续期记录。
- 想先试流程：命令前加 `LEGO_SERVER=letsencrypt-staging`（测试证书，不会装到 Nginx）。
- 以后有了备案的域名：`bash cert.sh <IP> <域名>` 重新申请一次，参数会记在 `/etc/engnest-cert.env`。

## 3. 注册管理员账号

第一次启动会生成一个管理员邀请码：

```bash
ssh root@<服务器 IP> "journalctl -u engnest | grep 管理员邀请码"
```

浏览器打开 `https://<服务器 IP>:8766`（还是自签名证书的话，第一次点「高级 → 继续访问」），点「注册」，填这个邀请码，自己设用户名和密码。
之后在「设置 → 账号和邀请码」里给朋友生成邀请码。

## 日常

| 做什么 | 命令 |
|---|---|
| 看运行状态 | `systemctl status engnest` |
| 看日志 | `journalctl -u engnest -f`，详细的在 `/opt/engnest/data/logs/engnest.log` |
| 更新代码 | 按第 1 步重新上传，再 `systemctl restart engnest` |
| 生成邀请码（命令行） | `sudo -u engnest ENGNEST_DATA_DIR=/opt/engnest/data /opt/engnest/venv/bin/python /opt/engnest/app/main.py --invite` |
| 列出账号 | 同上，把 `--invite` 换成 `--users` |
| 备份 | 每 6 小时自动备份每个人的进度到 `data/backups`、`data/profiles/<id>/backups`（保留 7 天）；整个 `/opt/engnest/data` 打包下载就是完整备份 |

## 安全

- 密码只存加盐哈希（scrypt）；登录凭证 30 天不用就过期；同一个 IP 10 分钟内输错 5 次锁 10 分钟。
- 各人的 AI Key 用服务器上的密钥文件 `data/.secret.key` 加密（权限 600）。别把这个文件和 `settings.json` 一起发给别人。
- 程序以 `engnest` 用户运行，只能写 `/opt/engnest/data`。
- 换成正规证书以后浏览器不再提示「不安全」，也能正常缓存网页（见 2.5）。
